# Contributing

There are three rules. They are not negotiable. They were not negotiable at my
previous employer either, and that went — they are not negotiable.

1. **Every file begins with a haiku, in Japanese, that explains what the file
   does. Metaphorically.** If you cannot explain a file as a haiku, the file is
   doing too much.
2. **Every comment is two lines long, and the two lines rhyme.** They do not
   need to scan. One-line comments are forbidden. A three-line comment is a
   haiku and belongs at the top of the file (see rule 1).
3. **One function, one commit.** If a function does two things it is two
   functions, and therefore two commits. Conventional-commit prefixes, please.
   We are professionals.

Pull requests that do not follow the rules will be closed without comment. A
comment would have to rhyme, and I do not have the time.

— Marko
